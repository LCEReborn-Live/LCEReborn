# LCEReborn Live 1.0.7

This update preserves the original mini-game **Create | Join** labels while fixing the join menu.

- Initialized the join menu list so its existing **Join** action is registered and displayed.

The search joins over direct networking when available and falls back to relay.

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
