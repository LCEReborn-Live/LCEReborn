# LCEReborn Live 1.0.13

The News page now loads release information reliably when GitHub's unauthenticated API quota is exhausted.

## Improved

- LCEReborn Live and original LCEReborn release news now use GitHub's public Atom feeds instead of the rate-limited REST API.
- Release notes are cached locally in the launcher's normal data folder.
- Live update checks keep a direct installer download link for stable version releases.
