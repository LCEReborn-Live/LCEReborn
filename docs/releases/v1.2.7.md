# 1.2.7 — Nintendo Switch and Wii U Beta

This release brings LCE Live to Nintendo Switch and expands the Wii U port. Windows and Linux keep their existing launcher and dedicated server packages.

## Nintendo Switch Beta

- Added a native homebrew client with controller input, offline worlds and saves.
- Added LCE Live sign-in by code, session restore after restart, friends, requests, invitations and notifications. The Switch client uses the same account UUID as the PC launcher.
- Added the client paths for LAN and Relay multiplayer, minigame matchmaking, leaderboards and achievement sync. Corrected parsing of numeric IDs and cosmetic flags so friends, avatars and achievements can load.
- Modern Textures 1.14 is included. Corrected the shield texture paths, item icons, texture-pack selection and inventory lighting.
- The Switch TCP transport now uses nonblocking reads and writes. Position corrections and chunk streaming still need longer tests across LAN, Relay and real hardware.

Copy **`LCEReborn-Full.nro`** into `switch/` on the SD card and open it from the Homebrew Menu in application mode. It includes the base game assets, Update 688, Modern Textures and client resources. The smaller **`LCEReborn.nro`** includes the client resources and uses prepared game data in `switch/LCEReborn/assets/`.

## Wii U Beta

- Added sign-in by code and saved sessions, friends and invitations, direct and Relay multiplayer, leaderboards and achievement sync.
- Fixed Cemu startup when Mii graphics are unavailable, Live connection handling, profile selection when joining, and skin geometry for custom Live skins.
- Added the shield and Modern Textures. Both the lightweight WUHB and the complete WUHB are available.

Use the **Wii U Full Beta `.wuhb`** with Aroma or the Cemu launch helper. It includes the base game assets and Update 688. The lightweight WUHB uses game data in `wiiu/LCEReborn/content/`. A standalone RPX and its link map are also included.

## LCE Live and build improvements

- The website supports code sign-in for Wii U and Nintendo Switch. The friends list can show **Playing on Wii U** and **Playing on Nintendo Switch**.
- Added compiler caches for Windows, Linux and Switch builds. Windows can compile with up to four parallel jobs. Wii U Actions also reuses the RedHills build and can produce complete WUHB packages.

The Windows, Linux, Wii U and Switch builds passed integration checks. The console clients are beta. Mixed-platform Relay sessions and complete online Battle, Tumble and Glide rounds still need broader testing.
