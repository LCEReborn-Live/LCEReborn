# LCEReborn Live 1.2.2 — Bugfixes!

This update improves the in-game Live menus, achievement synchronization, and launcher notifications.

### Fixed

- Corrected the width and alignment of the **Packs** and **LCE Live** buttons in the main menu.
- Updated mouse hit detection in **Friends**, **Requests**, **Invites**, and the in-game friend invitation picker to follow the visible menu elements. Added mouse wheel navigation and right-click back.
- Fixed a Windows issue that could prevent previously earned achievements from being uploaded after the player profile finished loading.
- Removed a dynamically created main-menu button that could refer to unloaded interface data after leaving a world.
- Added checks for missing and out-of-range FUI animation frames when looking up a frame label.

### Added

- The launcher can stay in the system tray when its window is closed, keeping Live notifications available in the background. Use the tray icon to reopen it or exit completely.

Achievement synchronization and menu interaction require the updated client. Existing achievements are uploaded when their owner starts the game while signed in to Live.
