# LCEReborn Live 1.0.12

Mini-game matchmaking now follows the native Legacy Console Edition flow more closely.

## Improved

- Find Match entries for Battle, Tumble, and Glide appear only in the mini-game Join menu.
- Selecting a mode opens its native matchmaking screen with the available filters and Join action.
- The game no longer starts matchmaking immediately when that screen opens.
- The regular world Join list keeps Add Server and local network discovery without mini-game matchmaking entries.
