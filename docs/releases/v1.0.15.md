# LCEReborn Live 1.0.15

Online worlds now support in-game voice chat with the open-mic behavior familiar from Minecraft: Wii U Edition.

## Added

- **Game Chat:** Enable voice chat from the in-game Audio settings while playing online.
- **Open microphone:** Speech is transmitted automatically while the setting is enabled; there is no push-to-talk key.
- **Voice activity detection:** Silence is filtered before voice data is sent.
- **Relay-compatible voice:** Voice packets use the game's current multiplayer connection, including its relay path.
- **Player indicators:** Existing LCE voice indicators show who has voice enabled and who is speaking.
- **Opus encoding:** Voice is compressed for online play.

## Improved

- The Windows updater starts downloaded installers through the system shell, reports the Windows launch error, and keeps the installer for manual opening if launch fails.
- Portable archives place the launcher and game executables at the archive root, avoiding an extra nested `LCEReborn` folder when extracted into a folder with that name.
- The release workflow verifies that the portable archive contains the launcher before it builds the installer.
