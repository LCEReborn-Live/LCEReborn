# LCEReborn Live 1.3.0

Windows and Linux packages now include the complete prepared game assets, including Village & Pillage menus, textures, sounds and local structure templates. Install the game and play without a separate game-data download or import.

## Downloads

Choose one client download for your platform. Each file includes its own game assets; you do not need to download the other packages.

- **Windows installer:** `LCEReborn-Live-Installer-1.3.0.exe`.
- **Windows portable:** `LCEReborn-Live-Portable-1.3.0.zip`.
- **Linux AppImage:** `LCEReborn-Live-Linux-1.3.0.AppImage`.
- **Linux portable:** `LCEReborn-Live-Linux-Portable-1.3.0.tar.gz`.
- **Dedicated servers:** `LCEReborn-Live-Server-Windows-1.3.0.zip` and `LCEReborn-Live-Server-Linux-1.3.0.tar.gz`. These are only needed for hosting a dedicated server.

## Changes

- Bundled all prepared game resources with the launcher and dedicated server packages.
- Made the Linux launcher use bundled assets, including inside the AppImage, while keeping saves and profiles in the user's data directory.
- Removed the separate 1.14 Texture Pack from the distribution. The Windows installer also removes the two old pack files when updating an existing installation.
- Added asset checksums to detect missing or changed content before packaging.
- Fixed release packaging to accept verified game archives and added tests that create and read back Windows ZIP and Linux tar.gz packages.

Keep the `assets` directory beside the launcher when using a portable package. The installer places it automatically.
