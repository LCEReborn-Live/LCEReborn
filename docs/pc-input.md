# Controls on PC

You can play with a keyboard and mouse, controllers, or both at once for split screen.

## Keyboard and mouse

The default keys follow Minecraft on PC. The mouse looks around in game and points and clicks in menus. In menus, the wheel scrolls and right-click or Escape goes back.

A few extra keys:

| Key | What it does |
| --- | --- |
| T | Chat |
| `/` | Chat with a command started |
| Tab | Player list |
| F1 | Hide the HUD |
| F3 | Debug overlay |
| F11 or Alt+Enter | Fullscreen |

## Controllers

Xbox, PlayStation and Nintendo controllers all work, and the on-screen prompts show your controller's own buttons. The confirm button confirms and the back button goes back, whichever controller you're using.

## Split screen

Whichever device picks an option on the main menu is player 1. In game, double-tap Start on another controller, or press Escape on an unused keyboard, to join as the next player. Each player can set their own field of view.

Split screen can be turned off in the launcher profile.

## Rebinding

Help & Options > Controls rebinds whatever device you're using. Pick a row, then press the new key or button. Escape cancels. Keyboard bindings are saved to `keybinds.txt` in the save folder. Controller bindings are saved in your profile.
