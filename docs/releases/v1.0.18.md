# LCEReborn Live 1.0.18 — Controller FPS Fix

This update fixes controller input that became too fast after enabling uncapped frame rates.

- **Inventory cursor:** Movement and acceleration now follow elapsed time, keeping the cursor controllable at high FPS.
- **Controller chat:** Navigation repeat delays use milliseconds instead of rendered frames.
- **Chat caret:** The blinking cursor keeps a consistent speed regardless of FPS.

Uncapped rendering remains available, and VSync keeps its existing setting.

Both the Windows installer and portable package include these fixes. Update from the launcher or download the package that matches your installation.
