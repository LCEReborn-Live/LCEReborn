# LCEReborn Live 1.0.6

This update makes mini-game matchmaking visible and selectable in game.

## Fixed

- Initialized the mini-game join menu list so its controls are registered and displayed.
- Renamed the join action to **Find Match** to make its matchmaking behavior clear.

The button searches for a compatible open Live mini-game and joins through direct networking or relay fallback.

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
