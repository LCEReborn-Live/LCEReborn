# 1.2.4 — Texture Pack & World Generation Fixes

This update fixes crashes when using Old Textures and generating world structures.

## Bug fixes

- **Old Textures** — fixed incorrect resource paths that caused the game to close while loading textures such as `cavespider.png`.
- **World generation** — fixed a missing data fixer when loading structure templates with the built-in 1.14 texture pack or other DLC texture packs, which could cause an access violation (`0xC0000005`).
- **Crash diagnostics** — the launcher now shows the game's exit code, including its hexadecimal Windows code, instead of only reporting that the game crashed.

## Validation

Verified four complete switches between Old Textures and 1.14, including indexed textures, atlases and colour maps, and 752 structure-template loads across both packs. Original cave spider pixels were checked against the base game.
