# LCEReborn Live 1.1

More consistent controller inventory navigation and friend request notifications in the launcher.

### Controller inventory fix

- Fixed fractional cursor movement being discarded, which could make vertical movement stop while horizontal movement continued, especially in split-screen.
- Cursor speed and acceleration now follow elapsed time across different frame rates.
- Improved movement during uneven loading frames and switched the cursor timer to a monotonic clock.
- Preserved slot snapping, interface sensitivity, and the split-screen speed setting.

### Friend request notifications

- Incoming friend requests now show an animated notification with the player's skin face and the invitation sound.
- Accept or decline directly from the notification. Failed requests can be retried.
- Repeated refreshes do not repeatedly announce the same pending request during the launcher session.

Uncapped rendering and the existing VSync setting remain available. Windows installer and portable packages are included.
