# LCEReborn Live 1.0.16

Game Chat now suppresses background noise before voice is sent to other players.

## Added

- **Microphone noise suppression:** RNNoise cleans captured speech in real time before Opus encoding. It runs locally in the game; voice audio is not sent to a separate processing service.
- **Voice activity detection after cleanup:** The existing open-mic behavior now decides when to transmit using the cleaned audio.

## Improved

- Mini-game matchmaking waits three seconds and checks the available sessions again before showing the game's localized **No Games Found** message.

Game Chat remains available from the in-game Audio settings. Noise suppression reduces background sounds, but headset feedback and loud sounds mixed with speech may still be audible.
