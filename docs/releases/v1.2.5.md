# 1.2.5 — Texture Packs, DLC, and Live Identity

This update improves texture pack and DLC handling, fixes a leaderboard crash, and gives LCE Live players a consistent identity across devices.

## Changes

- **Modern Textures** (the 1.14 pack) is now the default, with classic **Minecraft** textures available as a selectable option. The pack list puts Modern Textures and Minecraft first.
- Added support for all original DLC packs from the imported `WiiU/DLC` and `WiiU/CU/DLC` folders. Returning from a DLC world restores the selected texture pack, and Modern Textures uses the game's default sounds.
- Players signed in to the same **LCE Live** account now use the same player identity across devices, so multiplayer worlds can recognize them when they switch computers.
- Fixed a leaderboard crash when a server connection is unavailable.
