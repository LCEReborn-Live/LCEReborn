# LCEReborn Live 1.0.8

This update adds mini-game matchmaking actions to the **Join** tab.

## Added

- Added **Find Match: Battle**, **Find Match: Tumble**, and **Find Match: Glide** rows to the mini-game Join list.
- Selecting a row immediately searches for a compatible open Live game and joins using direct networking or relay fallback.
- Kept the original **Create | Join** tab names and the existing server and LAN rows.

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
