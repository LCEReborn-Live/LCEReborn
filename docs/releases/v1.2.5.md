# 1.2.5 — Texture Packs, DLC, and Live Identity

This update improves texture pack and DLC handling, fixes a leaderboard crash, and gives LCE Live players a consistent identity across devices.

## Changes

- **Modern Textures** is now the default pack, with classic **Minecraft** textures available as a selectable option. The pack list puts Modern and Minecraft first, and Modern Textures uses its own icon and description.
- Added support for all original DLC packs from the imported `WiiU/DLC` and `WiiU/CU/DLC` folders. Returning from a DLC world restores the selected texture pack, and the 1.14 pack uses the game's default sounds.
- Players signed in to the same **LCE Live** account now use the same player identity across devices, so multiplayer worlds can recognize them when they switch computers.
- Replaced the main-menu logo with the **LCEReborn-Live** artwork.
- Fixed a leaderboard crash when a server connection is unavailable.
