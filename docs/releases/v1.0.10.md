# LCEReborn Live 1.0.10

Launcher updates are easier to find and install, and the News tab now includes releases from both LCEReborn Live and the original LCEReborn project.

## Added

- The launcher checks Live releases for a newer stable build and shows an **Update** button when its installer is available.
- For installed copies, the Update button downloads the installer, checks that it is a Windows executable, and opens the normal installer so you can review and confirm the installation. Portable copies open the release page to download the new archive.
- News now combines and labels Live and original LCEReborn release notes. Update checks only use Live releases.

## Improved

- Build tags and precise build timestamps prevent the launcher from offering its own release as an update or missing a release published on the same day.

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
