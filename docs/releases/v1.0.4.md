# LCEReborn Live 1.0.4

This update refreshes incoming game invitation notifications.

## Added and fixed

- Replaced the red notification styling with a rounded stone-like Minecraft theme and pixel-style buttons.
- The invitation shows the inviter's skin face, with their initial as a fallback.
- Added the supplied PlayStation trophy sound when an invitation appears.
- Included the sound in Windows and Linux packages.

## Downloads

- **Windows installer:** `LCEReborn-Live-Installer-1.0.4.exe`
- **Portable build:** `LCEReborn-Live-Portable-1.0.4.zip`

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
