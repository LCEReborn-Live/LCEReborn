# 1.0.17 fps patch

The Windows client no longer has a fixed 60 FPS limit. VSync remains available and keeps its existing setting. With VSync disabled, rendering runs without the fixed frame cap.

Controller inventory cursor movement and acceleration now follow elapsed time, preserving their normal speed at high frame rates. Controller chat navigation repeats and the chat caret animation also use elapsed time instead of rendered frames.

This patch keeps version 1.0.17 and includes the improvements listed below.

This release adds configurable limits for voice traffic and the Live service ahead of public use.

- **Game Chat:** The host now limits voice packet frequency and audio bytes per player. Excess audio is dropped without interrupting the match.
- **Live API:** Separate IP and account budgets protect registration, authorization, room creation, join tickets, invitations, presence, and reads. Busy clients receive HTTP 429 with a retry time.
- **Relay:** Global room, connection, pending join, and bandwidth limits help keep the relay responsive. Room capacity errors return HTTP 503.
- **Mini-game search:** An animated progress screen appears while looking for a match and closes before the no-games result.
- **Windows updates:** The launcher closes before installation, then reopens after the update finishes. A separate updater handles temporary Windows file locks.

The multiplayer packet format, direct connection path, invitations, and matchmaking behavior remain the same. Service limits and voice limits can be adjusted by operators through environment variables.
