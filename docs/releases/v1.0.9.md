# LCEReborn Live 1.0.9

This update makes mini-game matchmaking available directly from the main **Join** tab.

## Added

- Show **Find Match: Battle**, **Find Match: Tumble**, and **Find Match: Glide** for signed-in Live players in the Join list.
- Selecting an action immediately searches for a compatible open Live game and joins over direct networking or relay.
- Preserve the original **Create | Join** tabs, Add Server action, server list, and LAN scanning row.

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
