# 1.2.5 — Some Bugfixes

This update fixes texture pack, DLC, audio, and leaderboard issues.

## Fixed

- Made **Modern Textures** the default pack and kept classic **Minecraft** textures selectable directly after it.
- Added the Modern Textures icon and fixed its packaging for PC builds.
- Load DLC directly from imported `WiiU/DLC` and `WiiU/CU/DLC` folders, while keeping the `packs` folder available for custom packs.
- Use the game's default music with Modern Textures instead of attempting to open missing audio files from the texture pack.
- Restore the default texture pack when leaving DLC worlds.
- Prevent a leaderboard request from crashing when no local player connection exists.
