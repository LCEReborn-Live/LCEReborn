# LCEReborn Live 1.1.2

**From your friends list straight into the game.** Join an available friend's world from [lcereborn.xyz](https://lcereborn.xyz) or directly from the launcher's Friends tab.

### Join together

- The website's **Join** button opens LCEReborn Live and passes the selected world to the launcher.
- **Join** appears beside a friend when their online world is available to your account. The launcher checks access again before connecting.
- If the game is closed, the launcher starts it with your selected profile. If it is already running, the request is sent to that launcher without opening a second copy.
- Sign-in can be completed before a pending join continues. When already playing in a world, return to the main menu to join your friend.
- Connections use the existing direct/P2P route or Relay fallback, with the normal account and join-ticket checks.

### Friends activity

- Friends now show the original **Battle**, **Tumble** and **Glide** icons beside their activity text.
- Names and presence use separate lines for clearer reading, including **On Website**, **In Launcher** and **In Game**.

### Browser setup

The Windows installer enables browser joins automatically. For a portable copy, open **Friends → Enable browser joins** once, and register again if you move the folder. The website also provides launcher download and setup instructions.

Available as a **Windows installer** and **portable ZIP**.
