# LCEReborn Live 1.0.3

This update makes personal leaderboard results appear locally and reach Live sooner.

## Added and fixed

- **My Score** and **My Statistics** show the current local profile's score when Live has no saved result yet or the API cannot be reached.
- Changed leaderboard statistics are submitted after about one second instead of waiting several minutes.
- Friend statistics also fall back to the local profile when the server has no rows to show.

## Downloads

- **Windows installer:** `LCEReborn-Live-Installer-1.0.3.exe`
- **Portable build:** `LCEReborn-Live-Portable-1.0.3.zip`

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
