# LCEReborn Live 1.1.3

**LCEReborn Live comes to Linux.** The launcher, game, and Live networking are now packaged for Linux alongside the Windows releases.

### Linux support

- Download an AppImage or a portable `.tar.gz` from the release assets.
- The Linux packages include the Live bridge and Node.js 22 runtime; a separate Node.js installation is not required.
- Friends, invitations, joinable worlds, leaderboard requests, and the existing game networking work through the Linux Live file bridge.
- Linux users can register `lcereborn://` browser joins from the Friends page. AppImage registrations continue to point to the AppImage file.
- The launcher detects new Linux releases and opens the AppImage download. Replace the portable AppImage manually after downloading it.

### Windows and Linux builds

- GitHub Actions now builds both platforms and publishes their assets together for version tags.
- The existing Windows installer and portable ZIP remain available.
- Packages contain no game content, saves, account tokens, or personal files. Import your own game and Update 688 files through the launcher.

The Linux portable archive requires a 64-bit Linux desktop and the glibc version stated in its `README.txt`. The AppImage and archive include the launcher and Live networking components.
