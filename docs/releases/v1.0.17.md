# LCEReborn Live v1.0.17

This release adds configurable limits for voice traffic and the Live service ahead of public use.

- **Game Chat:** The host now limits voice packet frequency and audio bytes per player. Excess audio is dropped without interrupting the match.
- **Live API:** Separate IP and account budgets protect registration, authorization, room creation, join tickets, invitations, presence, and reads. Busy clients receive HTTP 429 with a retry time.
- **Relay:** Global room, connection, pending join, and bandwidth limits help keep the relay responsive. Room capacity errors return HTTP 503.

The multiplayer packet format, direct connection path, invitations, and matchmaking behavior remain the same. Service limits and voice limits can be adjusted by operators through environment variables.
