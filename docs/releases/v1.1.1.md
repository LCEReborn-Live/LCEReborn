# LCEReborn Live 1.1.1

Live has a new home at **[lcereborn.xyz](https://lcereborn.xyz)**. This update connects the launcher and game bridge to the new API address and opens browser sign-in on the main website.

### Updated Live connection

- Account sign-in, saved sessions, friends, invitations, presence, skins and capes now use `api.lcereborn.xyz`.
- Browser authorization opens `lcereborn.xyz/authorize`.
- The game bridge uses the same new API for world discovery, matchmaking and relay coordination.
- Existing saved launcher sessions remain valid. Relay endpoints continue to come from the API automatically.

### Compatibility

Older clients can keep connecting through the existing API domain. This release also includes the controller cursor improvements and friend request notifications from 1.1.

Both the **Windows installer** and **portable ZIP** are included. Your launcher account, profiles and worlds are preserved when updating.
