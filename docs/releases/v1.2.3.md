# 1.2.3 — Shields & 1.14 Textures · Patch 1

Shields join the fight, alongside a fresh look with Minecraft 1.14 textures.

## What's new

- **Shields** — added as a usable item and available as rare chest loot in Battle minigames.
- **Minecraft 1.14 textures** — now built in as the default. Prefer the original look? Select **Old Textures**.

## Bug fixes

- Fixed an issue where the controller cursor could get stuck in the inventory.
