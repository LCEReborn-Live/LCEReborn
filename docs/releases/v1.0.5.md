# LCEReborn Live 1.0.5

This update adds the first playable Live matchmaking flow for LCE mini-games.

## Added

- Matchmaking worlds publish their mini-game type and selected search filters to Live.
- The Find Game action searches visible, active Live worlds for a compatible mini-game.
- Compatible games join through the existing direct connection when available, with relay fallback.
- Matchmaking rooms are published as public so players outside the host's friend list can find them.
- Existing world listings remain compatible with older `world.txt` records.

## Current scope

Search finds a compatible game that is already open. Waiting queues and automatic game hosting are not part of this release.

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
