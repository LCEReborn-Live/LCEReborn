# LCEReborn Live 1.0.2

This update fixes leaderboard filter navigation in the PC game.

## Added and fixed

- The leaderboard filter hint is visible as soon as the menu opens.
- Press **X** on the keyboard or controller to cycle through **Global**, **My Score**, and **Friends**. With a mouse, use the right button.
- The filter can be changed from the main-menu leaderboard as well as while a world is open.

## Downloads

- **Windows installer:** `LCEReborn-Live-Installer-1.0.2.exe`
- **Portable build:** `LCEReborn-Live-Portable-1.0.2.zip`

The downloads contain the client and launcher, not game content. Import your own base-game and Update 688 files through the launcher.
